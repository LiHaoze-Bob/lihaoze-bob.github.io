## 乘法 {#乘法}

32 位无符号乘法
被乘数 `M` 保持不动，`P` 的高 32 位存部分积，低 32 位先装乘数。

1. 初始化 `P = {32'b0, multiplier}`。
2. 看 `P[0]`：为 1 时，高 32 位加上 `M`；为 0 时不加。
3. 将加法结果与低 32 位拼接，整体右移一位。

加法中间结果要留 33 位，保住进位：

```verilog
assign sum = {1'b0, P[63:32]}
           + (P[0] ? {1'b0, M} : 33'b0);
P <= {sum, P[31:1]};
```



## 除法 {#除法}

恢复余数法和手算竖式一样：从被除数最高位开始，每次带下一位，试着减一次除数。这里先假设除数不为 0。

`P` 的高 32 位存余数，低 32 位先装被除数，计算中逐渐被商替换；除数 `D` 保持不动。

1. 初始化 `P = {32'b0, dividend}`。
2. 左移并带下一位，临时余数为 `shifted_r = P[63:31]`。
3. 试减 `diff = shifted_r - {1'b0, D}`。够减则保留差、商位填 1；不够减则保留 `shifted_r`、商位填 0。
4. 重复 32 轮，最后 `P[63:32]` 是余数，`P[31:0]` 是商。


## 浮点加法 {#浮点加法}

单精度浮点数分成符号 `S`、8 位阶码 `E`、23 位小数 `F`。规格化数的值为：



$$
(-1)^S\times(1.F)_2\times2^{E-127}
$$



运算前补回隐藏位 `1`，然后按下面的顺序处理：

1. 对阶：小阶码的尾数右移，移位数等于阶码差。
2. 尾数加减：同号相加，异号按绝对值大小相减，结果符号取绝对值较大的数。
3. 规格化：调整成 `1.xxx`。尾数右移时阶码加 1，左移时阶码减 1。
4. 舍入，再打包成 32 位结果。

如 `1.5 + 0.75`：

```text
对阶：1.100₂ × 2⁰ + 0.110₂ × 2⁰
相加：10.010₂ × 2⁰
规格化：1.001₂ × 2¹ = 2.25
```

特殊值要在普通运算前判断：

| 编码 | 含义 |
| --- | --- |
| `E = 255，F ≠ 0` | NaN |
| `E = 255，F = 0` | 正负无穷大 |
| `E = 0，F = 0` | 正负零 |
| `E = 0，F ≠ 0` | 非规格化数，隐藏位为 0，实际指数为 −126 |

`+∞ + (-∞)` 得到 NaN
完全相消得到 `+0`
最近偶数舍入下，`-0 + (-0)` 保留 `-0`


!!! question
    舍入时保留 G、R、S 三位，S 是所有更低位的或。进位条件为 `G && (R || S || LSB)`，其中 LSB 是保留部分的最低位。舍入还可能产生进位，需要再调整阶码；上溢输出带符号的无穷大，过小的结果按非规格化数表示。
