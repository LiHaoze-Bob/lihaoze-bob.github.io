接下来是封装一些模块，通过IP来封装，然后放入ip_repo，这样就可以在其他工程中调用了。

RAM和ROM，没有完全搞懂。不过大致是，为了节约FGPA资源，我们可以使用vivado的内置memory generator。ROM是只读，一般存一些静态的数据。RAM是可读写的存储器，可以放变量，当wea为1时，即时钟上升沿，开始写入。然后我们就可以生成memory_ip，本质其实也是封装。

会发现coe文件相当于初始化，veo文件相当于接口说明。

下面给出RAM的主要接口
```verilog
.clka(clka),   // 时钟
.wea(wea),     // 写使能
.addra(addra), // 地址
.dina(dina),   // 准备写入的数据
.douta(douta)  // 读取的数据
```
